# MarketApp Smart Rent v0.4.0

Один файл плагина для FunPay Cardinal.

Что изменилось:
- `SETTINGS_PAGE=True`: в карточке плагина появится кнопка «Настройки».
- Отдельный файл с 78 лотами больше не нужен: соответствия встроены в `.py`.
- Плагин сам создаёт в `storage/plugins/` только свои служебные файлы:
  - `marketapp_smart_rent.json` — настройки;
  - `marketapp_smart_rent_state.json` — lot_id, статистика и последние заказы.
- Команда `/smartrent` открывает панель плагина.

Настройки в Telegram:
- включение логики плагина;
- автоаренда;
- Dry Run;
- повторная проверка MarketApp перед списанием;
- ответ покупателю;
- уведомления администратору;
- автоматическая привязка lot_id;
- максимальная сумма одной аренды;
- максимальный срок заказа;
- максимальное количество бонусных дней;
- проверка MarketApp API;
- статистика;
- список привязок lot_id;
- последние заказы;
- сброс lot_id.

По умолчанию:
- `auto_rent = false`
- `dry_run = true`

То есть сразу после установки TON не списывается.

Секреты читаются только из переменных окружения:
- `MARKETAPP_API_TOKEN`
- `MARKETAPP_WALLET_SEED`
- `MARKETAPP_TON_API_KEY`
- `MARKETAPP_WALLET_VERSION` (необязательно, по умолчанию V5R1)

Зависимость:
`pip install -U marketapp-api`

Перед установкой v0.4.0 удалите или замените старую v0.3.1: UUID у обновления тот же.
