# MarketApp Smart Rent

Плагин для FunPay Cardinal для автоматизации аренды Telegram NFT-подарков через MarketApp.

Текущая ветка разработки: **0.4.0.3**.

Основная логика:
- распознавание существующих FunPay-лотов без ручного добавления ID в описания;
- auto-binding `lot_id`;
- динамический запрос предложений аренды MarketApp;
- выбор минимальной **итоговой** стоимости среди предложений, срок которых покрывает оплаченный заказ;
- поддержка overdelivery, если более длинная аренда дешевле;
- Dry Run и защитные ограничения перед включением реальных TON-транзакций.

По умолчанию реальные списания должны оставаться выключенными до проверки на установленной версии Cardinal и MarketApp SDK.

## Секреты

Не храните API-токены, seed-фразы и приватные ключи в репозитории. Используйте переменные окружения или отдельное секрет-хранилище:

- `MARKETAPP_API_TOKEN`
- `MARKETAPP_WALLET_SEED`
- `MARKETAPP_TON_API_KEY`
- `MARKETAPP_WALLET_VERSION` — необязательно, по умолчанию `V5R1`

Для Auto-Pay рекомендуется отдельный low-balance TON hot wallet.
